# Blog hero image prompts

One prompt per blog post, written from the post's own text so the picture shows what the page is about. Style rule (always): **super-realistic, unretouched documentary photographs**: ordinary light, true-to-life color, lived-in surfaces, no cinematic grade, no glow, no glossy showroom look.

- Size: 16:9 landscape (the site crops and resizes to 1344x752 WebP).
- **Tire shop scenes (house rule, 2026-10-18): always clean.** Spotless polished light-gray floor, clean white walls, tidy tools; no stains, grime, oil or clutter, so the shop reads as clean.
- Vehicles are shown by body type only (no badges, logos, plates or brand names).
- File name = the post slug, saved as `public/brand/blog/<slug>.webp`; alt text lives in `src/data/blogImages.js`.
- Generated in ChatGPT (project TIRE DROP). The old Higgsfield set used a cinematic grade and was rejected on 2026-10-18 (audit: 49 of 49 read as AI).
